# Five-minute demo

1. Start the stack using README and open the dashboard.
2. Confirm the persistent Fixture data indicator. Submit a documented fixture URL.
3. Show the job moving through capture and audit. Inspect desktop/mobile evidence, selected DOM data, and failed objective checks.
4. Open a finding and trace its evidence IDs. Distinguish an objective defect from a design hypothesis.
5. Approve factual content and request a private redesign. Compare original and redesigned screenshots.
6. Inspect verification: fixed, unresolved, regressed, and unverified. Demonstrate that a failed required check prevents completion.
7. Show actual run duration, usage and unknown cost where pricing is unavailable. Explain that fixture results do not predict conversion.
8. Show the generated evaluation report, sample size and limitations. Live API and production security checks require separate verification.
